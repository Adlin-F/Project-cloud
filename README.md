# Project-cloud

Phase 2 cloud computing project with a React dashboard frontend and an Azure Function backend.

## Repo Structure

- `frontend/` - Vite + React dashboard
- `backend/` - Python Azure Function code

## Azure Static Web App Settings

Use these values when deploying the frontend from this repo:

- Repository: `Adlin-F/Project-cloud`
- Branch: `main`
- App location: `frontend`
- API location: leave blank
- Output location: `dist`
